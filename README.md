# CSO Trophy Studio — Concept Prototype 01

A separate, mobile-first prototype for Central Stand Outdoors' Digital Taxidermy product direction. It is intentionally separate from the existing hunting PWA so the live hunting app is not overwritten.

## Included
- Responsive iPhone-first interface
- Local photo picker and on-device preview
- Four mount concepts: classic shoulder, European, pedestal, outdoor portrait
- Optional trophy name/year, display setting and plaque finish
- Antler-accuracy preference
- Clear disclosure that the AI generation backend is not connected

## Not included yet
- Actual AI image generation
- User accounts, cloud storage, payments or subscriptions
- Trophy-room library / sharing
- Exact anatomical or antler reconstruction guarantees

## Privacy
The prototype uses a browser object URL to preview the selected image. It does not upload the photo to a server or persist it after the page is closed.

## Run
Open `index.html` in a modern browser, or host the folder as a separate test page. Do not upload this over the existing CSO hunting app.
